## 🏛️ Creative & Architectural Vision

A design monograph created at the intersection of high-end editorial typography, physical spatial depth, and rigorous systems engineering.

- **Serene Luxury Light Aesthetic**: Warm, peaceful alabaster canvas (`#F7F6F2`) with soft diffusion glows, multi-layer physical shadows, and deep charcoal ink typography (`#080C12` / `#121824`) delivering **over 14:1 contrast ratio**.
- **Editorial Typography**: Pairing modern geometric typography (`Plus Jakarta Sans`) with luxury editorial serif accents (`Fraunces`) and technical monospace coordinates (`JetBrains Mono`).
- **3D Spatial Architecture**: Genuine perspective depth using native CSS `perspective`, `transform-style: preserve-3d`, `translateZ()`, `rotateX()`, and `rotateY()`.
- **Zero-JavaScript Interactions**: Interactive 3D spatial rig, kinetic card fan, mobile navigation drawer, and micro-hover states powered 100% natively by CSS.

## 🚀 GitHub Pages Deployment

This portfolio is automatically deployed using GitHub Actions or direct GitHub Pages branch serving:

1. **Option A (GitHub Actions - Default)**:  
   Whenever a commit is pushed to the `main` branch, the `.github/workflows/deploy.yml` workflow automatically builds and publishes the site to GitHub Pages.
2. **Option B (Deploy from Branch)**:  
   In GitHub repository settings → **Pages** → Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → Save.
